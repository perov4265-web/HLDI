# HLDI — управление лазерным экспонированием (порт на Python)

Реализация на Python/PySide6 оригинальной программы HLDI на Forth — управление
лазерной установкой прямого экспонирования для засветки рисунка печатных плат.
Это рабочий прототип, который портирует важнейшую логику оригинала (протокол
обмена, разбор Gerber, модель устройства и движок построчного экспонирования)
за современным десктопным интерфейсом.

## Что портировано

Оригинал (`SOFT.zip`) — это программа на Win32 Forth примерно на 10 000 строк.
Этот порт воспроизводит части, которые определяют, что именно *делает*
установка, и заменяет обвязку Forth/Win32 на идиоматичный Python и интерфейс на
Qt.

| Модуль оригинала | Эквивалент на Python | Примечания |
|---|---|---|
| `INC/Comport.forth` | `hldi/core/protocol.py` | Кадрирование пакетов, аддитивная контрольная сумма, ACK + цикл из 5 повторов |
| `INC/Comport.forth` (ввод/вывод порта) | `hldi/hardware/serial_backend.py` | `OpenComPort`/`WCOM`/`RCOM`/`SendValCMD` поверх pyserial |
| `INC/hardctrl.forth` | `hldi/hardware/serial_backend.py` | `MoveToX/Y`, `StepsX/Y`, скорость, мощность лазера, преобразование шаг↔мкм |
| `INC/common.forth` (`SCNF`) | `hldi/core/config.py` | Конфигурация устройства; хранится в JSON вместо реестра |
| `INC/gerber.forth` | `hldi/core/gerber.py` | Парсер RS-274X → геометрические примитивы |
| `INC/texposer.forth` | `hldi/core/exposure.py` | Цикл растрового челночного экспонирования (`RunExposerOne`) |
| `INC/Option.forth` | `hldi/gui/settings_dialog.py` | Диалог конфигурации устройства |
| `INC/capture.forth` + `INC/DS_DEF.forth` | `hldi/hardware/camera.py`, `hldi/gui/camera_panel.py` | Камера совмещения (DirectShow → OpenCV) с накладным прицелом |
| Просмотр/отрисовка Win32 в `main.forth` | `hldi/gui/gerber_view.py` | Просмотрщик Gerber с зумом/панорамой и прицелом головки |
| `hldi.forth` / `main.forth` (цикл сообщений) | `hldi/gui/main_window.py`, `hldi/app.py` | Оболочка приложения |

### Апертурные макросы (`%AM%`)

Апертурные макросы Gerber поддержаны полностью (`hldi/core/aperture_macro.py`),
портирован механизм `vMacro` / `vArithm` из `gerber.forth`: тело `%AM%`
разбирается в примитивы, операнды которых — арифметические выражения (`$1+$2`,
`$3x0.5`, скобки, унарный минус), вычисляемые с параметрами вспышки при засветке
апертуры. Реализованы все стандартные примитивы — окружность (1), векторная
линия (2/20), центрированная линия (21), контур (4), многоугольник (5), муар (6),
термобарьер (7) — включая примитивы с выключенной засветкой, которые вычитают из
площадки (например, термобарьер или кольцо). См. `sample_macros.gbr`.

### Камера совмещения

Модуль камеры — кроссплатформенный порт окна захвата DirectShow. Поскольку
DirectShow есть только в Windows, бэкенд использует **OpenCV** (`cv2`),
работающий на Windows/Linux/macOS. Он перечисляет устройства, показывает
живой предпросмотр с накладным прицелом, смещённым на `CamOffX`/`CamOffY`,
выводит текущие координаты установки, делает снимки и сохраняет смещение
камера→инструмент в конфигурацию. OpenCV — **необязательная** зависимость:
если он не установлен, приложение всё равно работает, а вкладка камеры
сообщает о недоступности.

### Подключение к оборудованию

В панели подключения доступны четыре бэкенда:

- **Simulator** (по умолчанию) — устройство внутри процесса, приложение
  работает без оборудования.
- **Serial (USB)** — открывает заданный COM-порт и управляет контроллером с
  точным набором команд и форматом пакетов прошивки.
- **WiFi (network)** — подключается по TCP к контроллеру, найденному в
  локальной сети.
- **Bluetooth (BLE)** — подключается по Bluetooth Low Energy (нужен
  необязательный пакет `bleak`).

Для WiFi и Bluetooth нажмите **Scan for devices**: приложение рассылает
широковещательный UDP-запрос и слушает маяк устройства, а также сканирует BLE на
сервис HLDI, после чего выводит найденное в списке **Device**. Обнаружение,
буферизацию и автоматическое переподключение при обрыве связи обеспечивает
общий для транспортов базовый класс `ProtocolController` (`hldi/hardware/`)
вместе с `network_backend.py`, `ble_backend.py`, `serial_backend.py` и
`discovery.py`. Протокол обнаружения описан в `docs/PROTOCOL.md`.

> **О константах кадрирования.** Маркеры кадра и коды команд находятся в общем
> заголовке прошивки `hldi.h`. Этого заголовка не было в исходном архиве ПК,
> поэтому сначала их восстановили по коду на Forth; после добавления прошивки в
> репозиторий применены настоящие значения. Протокол в `hldi/core/protocol.py`
> теперь совпадает с прошивкой **побайтово** (маркеры `0xD6`/`0xE7`,
> последовательные ID команд 0–17). Полная спецификация, общая с прошивкой, —
> в `docs/PROTOCOL.md`.

## Функции из оригинального readme

Набор функций, описанный в `readme.txt` программы (история версий 042–057 и
заметки по использованию), отражён:

- **Экспонирование**: двунаправленная печать, переключатель режима мощности
  «мс/К*» (пересчитывается под текущую скорость), живые слайдеры «Скорость
  эксп» и «Огр. мощности лазера», пауза успокоения стола («Пауза усп»),
  разгон/торможение («Поле разг/торм»).
- **Изображение**: негатив / зеркало X / зеркало Y, наложение «Добавить
  Gerber», «Добавить кернение» (сверловка Excellon → незасвеченные кружки
  кернения, `hldi/core/excellon.py`).
- **Совмещение**: окно смещений (Сброс / `<-Уст` / `Уст->` / Устан / Точка /
  Смещ), привязка к левому/правому реперному отверстию, прозрачность прицела.
- **Окно ПИД**: челночный тест СТАРТ/СТОП с живым графиком скорости и
  напряжения на двигателе и слайдерами проп/интегр/дифф/Vmin, СОХР для
  сохранения.
- **Меню** Файлы / Отладка / Настройки и действия лазера (вспышка / вкл / выкл).
- **Горячие клавиши**: F1/F2/F3 — предустановки координат, F9 — быстрая
  вспышка, 1–0 — скорости каретки, Ctrl+1–0 — скорости свободного хода, стрелки
  — ручное перемещение (Shift = ¼, Ctrl = 10×, Ctrl+Shift = 100×),
  End/Home/PgUp/PgDn — углы платы, Ctrl+колесо — зум.
- **Исправления** из истории изменений: COM-порты выше 9 (v055), округление при
  пересчёте, исключающее накопление дрейфа шаг↔микрон (v056), сопоставление
  диаметра реперного отверстия диапазоном (v056).

## Что пока не вошло в прототип

- Прошивка загрузчика AVR (`calibrate.forth` / `update.forth`).

Это удобная точка для расширения, а не препятствие.

## Запуск

```bash
pip install -r requirements.txt
python run.py
```

Выберите бэкенд (Simulator или Serial), подключитесь, затем **Load Gerber…** и
**Run exposure**. Используйте панель ручного перемещения или **Go** для
позиционирования головки; **STOP** останавливает движение и выключает лазер.
Параметры устройства находятся в **Settings** и сохраняются в
`~/.config/hldi/config.json`.

## Структура

```
hldi/
  app.py                 точка входа
  core/
    protocol.py          кадрирование пакетов + контрольная сумма + ACK/повторы
    config.py            DeviceConfig (SCNF) + преобразование шаг↔мкм
    gerber.py            парсер RS-274X (+ апертурные макросы)
    aperture_macro.py    интерпретатор %AM% (порт vMacro / vArithm)
    exposure.py          движок растрового челночного экспонирования
  hardware/
    controller.py        абстрактный интерфейс Controller
    protocol_controller.py  логика команд, общая для транспортов (кадры/ACK/состояние)
    serial_backend.py    транспорт по USB serial
    network_backend.py   транспорт по WiFi (TCP) + авто-реконнект
    ble_backend.py       транспорт по Bluetooth LE (необязательный, нужен bleak)
    discovery.py         обнаружение по WiFi (UDP-маяк) + BLE
    simulator.py         симулятор внутри процесса
    camera.py            камера совмещения (OpenCV)
  gui/
    main_window.py       панель управления
    gerber_view.py       просмотрщик с зумом/панорамой
    camera_panel.py      живая камера + накладной прицел
    settings_dialog.py   конфигурация устройства
    theme.py             тёмная стилизация «промышленная консоль»
```
